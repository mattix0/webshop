# Webshop
A small webshop built to practice combining a frontend, backend, database, authentication and Docker in one project.

## Stack

* Frontend: Vanilla JS + HTML + CSS
* Backend: FastAPI
* Database: PostgreSQL
* Docker and Docker Compose

## Features

Customers
* Register and log in
* Add and remove products from the cart
* Check out an order

Admin
* Create, update and delete products
* View orders and customer data in a dashboard

## Project structure

* `frontend/` Frontend APP
* `backend/` FastAPI APP
* `docker-compose.yml` runs everything together
